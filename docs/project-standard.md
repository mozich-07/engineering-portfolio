# 作品集维护

首页按技术方向导航。能展示实物、代码或完整实验过程的作品可以保留独立页面。专题用于比较相关项目。每个完整项目提供独立页面和文件入口；短实践保存在专题的 details 目录，保留独立链接。实验源码、模型、结果、图片分别放在 src、models、results、assets，已有工程保留其运行所需的目录结构。每个案例按实际材料写清个人分工、方法或结果。

`catalog.json` 保存原有编号与当前落点，多条练习可以共用一个专题。移动文件时同步更新项目页、专题链接和自动检查的工作目录。

提交前运行 `python tools/check_repo.py`。固件改动检查 Uno 编译；工具改动运行对应的构建与测试。涉及实机或模型效果时记录测试条件。团队材料注明个人分工，第三方组件保留许可与署名。
